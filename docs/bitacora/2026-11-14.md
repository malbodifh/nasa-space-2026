## 4.1 PoC de datos (tarde)

Se construyó y ejecutó un PoC de punta a punta:

- `scripts/poc_spherex.py`: SIA2/CSV → cutouts → PNG → contact sheet + manifest.
- `scripts/align_diff.py`: reproyección a grilla común → stack → diferencia → GIF.

Resultados:
- WISE 0855: 10 épocas, alineación correcta, blink limpio.
- Barnard's Star: 12 épocas, alineación correcta, movimiento sub-píxel.
- La diferencia cruda es ruidosa; hay que apilar y medir centroides.
- El WCS del cutout coincide con la coordenada pedida (~1.7″).
- Los archivos quedaron en `data/cache/wise-0855/` y `data/cache/barnards-star/`.

Detalle en [15-validacion-datos.md](../15-validacion-datos.md).

## 4.2 Actualización data-first (cierre del día)

Se actualizó `docs/08-problemas-astrofisica.md` con:
- Inventario de las 14 APIs y su **Data Readiness Level**.
- Matriz **problema → dato → API → prototipo 48 h**.
- Lista explícita de **qué NO se puede hacer** con estos datos.
- Contrato de datos obligatorio por feature.

Conclusión: con las APIs dadas, los problemas fuertes son **movimiento, variabilidad, espectros, visualización y ciencia ciudadana**. Materia oscura, exoplanetas (atmósferas), Sol, Marte/Luna y ondas gravitacionales **no** se pueden atacar con estos datos.
