## 7. Cómo citar en documentos futuros

- Para un dato de misión: citar NASA/ASF y la fecha de consulta.
- Para un valor del código: citar el archivo y la función.
- Para una prueba: citar el documento de QA y la fecha.
- Para una hipótesis: escribir “hipótesis” y no “resultado”.
- Para una propuesta: escribir “propuesta” y no “implementado”.

**Nota sobre endpoints:** un GET sin parámetros puede devolver `400`, `406` o `403` (ASF Search,
CMR granules, Overpass, Photon, OSRM, GVP). Eso no significa que el servicio esté caído: falta la
consulta o el sitio bloquea bots. No interpretar esos códigos como “API obsoleta” sin una prueba
con parámetros válidos.
