# research/

Notas crudas, papers, capturas y pruebas que **no** son documentación final.

## Qué va acá
- Capturas de pantalla del Data Explorer.
- Resultados de pruebas de APIs (CSV, JSON).
- Papers o extractos.
- Comparaciones de herramientas.
- Fotos del evento (con permiso).

## Qué NO va acá
- Documentación estable → `docs/`.
- Datos pesados → `data/cache/` (gitignored).
- Código → `src/` o `scripts/`.

## Convención de nombres
```text
YYYY-MM-DD_tema_autor.md
YYYY-MM-DD_tema_autor.png
```
